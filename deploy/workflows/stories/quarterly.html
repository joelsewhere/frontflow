What an analyst sees

Region is the axis row-level security is drawn along, so the same page means different things to different people. An analyst scoped to East sees six of these rows; an administrator sees all fourteen.

That limit is enforced in the query rather than in the page, so it holds whether the data is reached through a dashboard, through Explore, or through SQL Lab.
