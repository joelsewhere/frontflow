What a story can do

This page is a reference. Each section demonstrates one capability, and the last one demonstrates a limit. View source on the rendered HTML to see exactly what reached the browser — nothing here is rewritten by frontflow.

Two different moments matter on this page:

  • Render time — when someone ran frontflow story render. Python and R cells run here, once, and their output is baked into the HTML.
  • View time — when you opened this page. Only JavaScript runs here.

2. Python, executed at render time

A cell runs when the page is built. The source is shown by default:

import datetime
print("rendered at", datetime.datetime.now().strftime("%H:%M:%S"))
rendered at 14:23:22

Reload this page: the time above never changes, because it is not being computed. That is the whole point of pre-rendering — the reader does not pay for the report.

#| echo: false hides the source and shows only the output:

East   ##################    6  (43%)
North  ############          4  (29%)
West   ######                2  (14%)
South  ######                2  (14%)

#| eval: false does the opposite — shows the code without running it, for when you want to talk about code rather than execute it.

5. Loading a library

Nothing in the response restricts script-src, so a story can pull a library from a CDN and use it. This is also how you would enable Observable JS: xmd emits an ojs cell as inert markup carrying its own source, and an Observable runtime you load yourself is what claims it.

6. The limit: this page is isolated

The document is served with a sandbox directive that grants allow-scripts but deliberately not allow-same-origin, so it runs on an opaque origin. It cannot read frontflow's cookies, its storage, or the page framing it — and neither can anything a story prints, which is what makes it safe to skip sanitising.

7. Taking over the whole document

If you want no shell at all, emit <!doctype html> from a {html} cell as the first thing in the file. frontflow detects it and serves your document byte for byte: no wrapper, no default styles, and no height reporter — so declare min_height on the panel in that case.

Rendering this

frontflow story render ./workflows
frontflow story render ./workflows --check   # CI: fails if stale

Edit this file without re-rendering and the workspace will tell you the page was built from an older source, rather than quietly serving stale output or re-running the report while you wait.
